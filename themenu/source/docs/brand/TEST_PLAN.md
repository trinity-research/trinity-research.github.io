## Session procedure

1. Show one wordmark for three seconds using a timer, then hide it. Ask “What name did you read?” Record the response verbatim before prompting.
2. Show the matching product card for three seconds, then hide it. Ask “What do you think this product helps you do?” Record purpose recognition separately from name recall. Wordmark-only purpose guesses may also be recorded, but do not combine those with the product-card result.
3. Show the small header-size mark again and ask what is easy or difficult to read. Repeat in grayscale using the same size. Record squinting, uncertainty, screen magnification, or letter confusion without assigning blame to the participant.
4. After a fixed two-minute unrelated task, ask for the remembered name without showing the mark. Record the same delay for all participants and all options. Repeated exposure to the same name can influence later responses; interpret order effects and delayed recall cautiously.
5. Repeat for the remaining colors in the assigned order. Then compare the two letter variants in the assigned SR/RS order, holding all other variables constant. Record whether the participant reads the lowercase word correctly and any perceived letter or name changes.
6. Ask preference last. Preference alone does not establish recognition, legibility, accessibility, or trademark availability.
